# Vine Rush: Jungle Swing

Build VINE RUSH: FIRST PERSON, a playable mobile-first browser game prototype, separate from any existing projects. First-person stylized 3D endless jungle vine-swinging game. Use Three.js with React Three Fiber and a lightweight physics implementation (or suitable physics library). Prioritize genuinely playable touch controls on iPhone: swipe/reach to target nearby vines, touch-and-hold to grab, release to launch, steering/body weight shifts; include desktop mouse fallback. Preserve physically plausible momentum, pendulum swinging, gravity, reachable grab radius, camera motion with comfortable reduced-motion option, visible hands/arms, procedural vine placement, endless distance score, falling/restart, simple tutorial overlay, and performant graphics. Keep all assets/code free and avoid paid services, subscriptions, backend, authentication, or API keys. First deliver a working MVP rather than elaborate menus; make mobile responsiveness and stable gameplay top priority. Give clear build status and any blockers.
